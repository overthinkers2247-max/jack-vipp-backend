# Jack Vipp backend

Secure Render starter for updating Firebase user access from an **authorized server-side integration or webhook**.

## Deploy on Render

- Runtime: **Node**
- Build command: `npm install`
- Start command: `npm start`
- Health check path: `/health`

Add these as Render Environment Variables. Do not commit real values:

- `FIREBASE_PROJECT_ID` — `jackvippannel`
- `FIREBASE_CLIENT_EMAIL` — from Firebase service-account JSON
- `FIREBASE_PRIVATE_KEY` — from Firebase service-account JSON; keep the `\\n` line breaks
- `SYNC_SECRET` — a long random secret generated by you

## Protected sync endpoint

`POST /sync-user`

Header:

```text
x-sync-secret: <SYNC_SECRET>
```

JSON body:

```json
{
  "phone": "9876543210",
  "registered": true,
  "balance": 500
}
```

This writes to `users/{phone}` in Firebase. The endpoint does **not** use browser passwords, cookies, or temporary Bearer tokens. Connect it only to an official API/webhook that you are authorized to use.
